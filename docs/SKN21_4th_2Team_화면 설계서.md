## 화면 구성 개요

명짝 서비스는 React 기반 SPA(Single Page Application)로, 채팅 인터페이스를 중심으로 구성된다.

### 주요 화면 구성 요소

1. **사이드바 (Sidebar)**
   - 상담사(유튜버) 선택 드롭다운 (13명)
   - 햄버거 메뉴 토글 (모바일)

2. **채팅 헤더 (Chat Header)**
   - 서비스 타이틀: "연애 상담소"
   - 인증 버튼 (로그인/회원가입/로그아웃)

3. **메시지 영역 (Message List)**
   - 사용자 메시지 (파란색 말풍선, 우측 정렬)
   - AI 응답 메시지 (노란색 말풍선, 좌측 정렬)
   - 캐릭터 애니메이션 (하트 이모지 변형)

4. **입력 영역 (Input Area)**
   - 텍스트 입력 필드
   - 전송 버튼

5. **인증 모달 (Auth Modal)**
   - 로그인 폼 (아이디, 비밀번호)
   - 회원가입 폼 (이름, 아이디, 이메일, 비밀번호)

## 화면 설계

### 메인 채팅 화면 (PC)

```
┌─────────────────────────────────────────────────────┐
│  [≡]  연애 상담소                    [로그인] [가입] │
├──────────┬──────────────────────────────────────────┤
│          │                                          │
│ 상담사   │    💛 안녕하세요! 연애 상담소에           │
│ 선택     │       오신 것을 환영합니다.               │
│          │                                          │
│ ┌──────┐ │              여자친구가 화났을 때    🔵  │
│ │권승현 │ │              어떻게 해야 하나요?         │
│ │주우재 │ │                                          │
│ │강 탱  │ │    💛 지금 상황은 여자친구가 화가        │
│ │김 달  │ │       난 상태야. 그녀가 화난 이유는...   │
│ │...    │ │                                          │
│ └──────┘ │                                          │
│          ├──────────────────────────────────────────┤
│          │  [메시지를 입력하세요...]        [전송]   │
└──────────┴──────────────────────────────────────────┘
```

│  └──────────────────┘  │
│                        │

## 화면 흐름 (User Flow)

```
[서비스 접속]
    │
    ├─→ [메인 채팅 화면] ←─── 비로그인 상태에서도 이용 가능
    │       │
    │       ├─→ [상담사 선택] → 페르소나 변경 → 대화 초기화
    │       │
    │       ├─→ [메시지 입력] → [AI 응답 스트리밍]
    │       │
    │       └─→ [로그인/가입 클릭]
    │               │
    │               ├─→ [로그인 모달] → 로그인 성공 → 채팅 화면
    │               │
    │               └─→ [회원가입 모달] → 가입 성공 → 채팅 화면
    │
    └─→ [회원정보 관리]
            ├─→ [프로필 조회]
            ├─→ [정보 수정]
            └─→ [비밀번호 변경]
```
